# SYNAPSE — Project Overview

## Summary

SYNAPSE is an evolving, human-directed AI engineering workflow and verification harness designed to keep problem framing, acceptance criteria, deterministic checks, and final approval under human control.

## Key Concepts

- **Human-Directed Control:** AI assists with planning, drafting, and analysis, while the engineer defines scope, runs checks, reviews evidence, and decides what is accepted.
- **Project Cells:** Isolated project-specific memory and continuity spaces that keep state, decisions, checkpoints, and work items separated across projects (such as CacaoGuard) to avoid cross-project context bleed.
- **Structured Discipline:** Uses explicit change/decision tracking, modular context assembly, and verification checks so progress stays traceable and reviewable.

## Boundaries

SYNAPSE is an active engineering system in development, not a claim of full autonomy or guaranteed output correctness. Core implementation, prompts, and project cells remain private.
