## About Me

I’m a graduating Computer Science student and an aspiring software engineer focused on building practical, reliable, and user-centered software. I develop full-stack applications, AI-enabled tools, and automation workflows that turn real-world requirements into maintainable products.

My experience spans software engineering, artificial intelligence, machine learning, backend development, and product-focused design. As I transition into the professional world, I’m actively seeking opportunities where I can contribute to engineering teams, continue growing through real-world experience, and help build technology that creates meaningful value.

## Areas of Interest

- Software Engineering and Full-Stack Development
- Artificial Intelligence and Applied Machine Learning
- Human-in-the-Loop AI Systems
- AI-Assisted Automation and Workflow Design
- Backend Systems, APIs, and Data Management
- Mobile and Product Development
- Software Quality, Testing, and System Design

## Selected Work Themes

My projects generally focus on the following areas:

| Area | What I build and explore |
| --- | --- |
| **AI Engineering Systems** | Human-directed AI workflows, prompt orchestration, context management, verification, and evidence-based development |
| **AI and Workflow Automation** | Structured pipelines that combine AI reasoning with deterministic execution, validation, rendering, and human approval |
| **Applied Machine Learning** | Model-backed applications, computer vision experiments, prediction systems, dashboards, and practical user workflows |
| **Full-Stack Product Development** | Web and mobile applications with authentication, databases, APIs, responsive interfaces, and user-focused features |

> My goal is to build software that is not only functional, but also understandable, testable, and useful to the people who rely on it.

## How I Work

1. Understand the problem, users, constraints, and success criteria.
2. Define a practical architecture and break the work into manageable tasks.
3. Build in small, reviewable increments with clear context and boundaries.
4. Use AI as a productivity and planning collaborator while keeping human judgment in control.
5. Validate the result with tests, checks, and practical evidence.
6. Document important decisions, trade-offs, and follow-up improvements.
