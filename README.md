## Featured Projects

### CacaoGuard · Android thesis application

An Android prototype exploring cacao-pod image classification and location-based detection records. The application brings together image input, on-device TensorFlow Lite inference, location-tagged detections, map views, local history, and backend services.

**Technologies:** Kotlin · Jetpack Compose · TensorFlow Lite · CameraX · Room · OSMDroid · Supabase  
[Project overview](docs/CACAOGUARD_OVERVIEW.md) · [Private source repository](https://github.com/kevinreylapiz-max/CacaoGuard)

> CacaoGuard is a prototype, not a validated agricultural diagnostic tool. The source repository is private; no public demo is currently available.

### SpendLore · Deployed expense journal

A web application for recording and reviewing personal expenses, with charts, date-based reports, searchable history, authenticator MFA, and an optional bring-your-own-AI workflow.

**Technologies:** React · TypeScript · Vite · Supabase · PostgreSQL · Playwright · GitHub Actions  
[Open the live application](https://spendlore.vercel.app)

The source repository is private.

### SYNAPSE · Human-directed AI engineering workflow

A local Python methodology and toolkit for structuring AI-assisted software engineering work. Used during CacaoGuard development, debugging, testing, thesis preparation and defense, and post-defense maintenance. Its workflow supports context continuity, checkpoints, project handoffs, smoke-test workflows, and human-directed multi-model orchestration.

[Project overview](docs/SYNAPSE_OVERVIEW.md) · [Workflow notes](AGENTIC_WORKFLOW.md) · [Private source repository](https://github.com/kevinreylapiz-max/Synapse)

> SYNAPSE helps organize context and work. The engineer directs tasks, reviews results, and decides what is accepted; it is not an autonomous AI system.
