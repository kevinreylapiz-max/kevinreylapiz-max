## How I Work

1. **Understand the problem** — define the user, constraints, and desired outcome.
2. **Break it down** — choose a simple architecture and identify the smallest useful version.
3. **Build deliberately** — write readable code and keep the system easy to change.
4. **Test and improve** — learn from feedback, failures, and real usage.
5. **Document the result** — explain decisions so the work is useful to others.
