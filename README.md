## Featured work

A selection of project work, with scope and evidence boundaries made explicit.

### CacaoGuard · Android thesis application

**An Android prototype for cacao-pod image classification and location-based records.**

Combined image capture, on-device TensorFlow Lite inference, location-tagged detections, map views, local history, and backend services. Completed and defended as a thesis project; development and maintenance continued after defense.

**Built with:** Kotlin · Jetpack Compose · TensorFlow Lite · CameraX · Room · OSMDroid · Supabase

[Project overview](docs/CACAOGUARD_OVERVIEW.md) · [Private source repository](https://github.com/kevinreylapiz-max/CacaoGuard)

> Prototype only—not a validated agricultural diagnostic tool. The source repository is private; no public demo is currently available.

### SpendLore · Deployed expense journal

**A web app for recording, searching, and reviewing personal expenses.**

Includes charts, date-based reports, searchable history, authenticator MFA, and an optional bring-your-own-AI workflow. The application is deployed; the source repository is private.

**Built with:** React · TypeScript · Vite · Supabase · PostgreSQL · Playwright · GitHub Actions

[Open the live app](https://spendlore.vercel.app)

### SYNAPSE · Human-directed AI engineering workflow

**A local Python methodology and toolkit for structured AI-assisted software engineering.**

Operationally used during CacaoGuard development, debugging, testing, thesis preparation and defense, and post-defense maintenance. Its workflow supports context continuity, checkpoints, project handoffs, smoke tests, and human-directed multi-model orchestration.

**Evidence available today:** 100+ recorded checkpoints are noted in the project workflow; publish a sanitized sample and reproducible verification artifacts before making broader claims.

[Project overview](docs/SYNAPSE_OVERVIEW.md) · [AI-assisted engineering workflow](AGENTIC_WORKFLOW.md) · [Private source repository](https://github.com/kevinreylapiz-max/Synapse)

> SYNAPSE structures context and work; the human engineer directs tasks, reviews results, and decides what is accepted. It is not an autonomous AI system.
